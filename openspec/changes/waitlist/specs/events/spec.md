## ADDED Requirements

### Requirement: Лист ожидания у типа билета

Система SHALL принимать при создании события необязательный признак `waitlistEnabled` у типа билета; признак допустим только для типов с ценой 0, по умолчанию выключен.

#### Scenario: Бесплатный тип билета с листом ожидания

- **WHEN** организатор создаёт тип билета с `price = 0` и `waitlistEnabled = true`
- **THEN** тип сохранён с `waitlist_enabled = true`, в ответе `GET /api/v1/events/{id}` признак виден участникам

#### Scenario: Платный тип билета

- **WHEN** организатор передаёт `waitlistEnabled = true` при `price > 0`
- **THEN** ответ 400 «Waitlist is available only for free ticket types»

#### Scenario: Признак не передан

- **WHEN** `waitlistEnabled` отсутствует в запросе
- **THEN** тип билета создаётся с выключенным листом ожидания, поведение регистрации прежнее

### Requirement: Очередь в кабинете организатора

Система SHALL отдавать организатору события очередь по типам билетов через `GET /api/v1/events/{id}/waitlist` с позицией, данными участника и временем постановки.

#### Scenario: Организатор смотрит очередь

- **WHEN** организатор события запрашивает очередь
- **THEN** возвращаются записи `waiting`, сгруппированные по типу билета, в порядке постановки

#### Scenario: Чужое событие

- **WHEN** очередь запрашивает другой организатор
- **THEN** ответ 403
