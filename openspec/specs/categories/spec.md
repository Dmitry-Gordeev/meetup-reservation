# Categories Specification

## Purpose

Категории событий (BC-02): фиксированный список платформы, которым управляет администратор. Источник: FR-08.4, `AdminController`, `EventsController.GetCategories`, таблица `categories`, seed `009_seed_categories.sql`.

## Requirements

### Requirement: Список категорий

Система SHALL отдавать список неархивных категорий через `GET /api/v1/categories` без авторизации; порядок — по `sort_order`.

#### Scenario: Категории для формы создания события

- **WHEN** организатор открывает форму создания события
- **THEN** доступны только категории с `is_archived = false`

### Requirement: Управление категориями администратором

Система SHALL позволять администратору создавать и редактировать категории через `GET/POST/PATCH /api/v1/admin/categories`, включая пометку архивной.

#### Scenario: Создание категории

- **WHEN** администратор отправляет `POST /api/v1/admin/categories` с уникальным названием
- **THEN** категория создана и появляется в списке

#### Scenario: Архивация категории

- **WHEN** администратор устанавливает `isArchived = true`
- **THEN** категория остаётся у существующих событий, но недоступна при создании новых

### Requirement: Начальный набор категорий

Система SHALL поставляться с seed-скриптом категорий (Конференции, Вебинары, Концерты, Мастер-классы, Встречи, Выставки, Фестивали, Спорт).

#### Scenario: Свежая установка

- **WHEN** применён `009_seed_categories.sql`
- **THEN** восемь категорий доступны для выбора
