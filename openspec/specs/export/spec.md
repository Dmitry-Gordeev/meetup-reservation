# Export Specification

## Purpose

Экспорт списка участников (BC-08) в Excel и PDF. Источник: FR-05.4, `RegistrationsController.Export`, `ExportService` (ClosedXML, PdfSharp).

## Requirements

### Requirement: Экспорт участников

Система SHALL формировать файл со списком участников события через `GET /api/v1/events/{id}/registrations/export?format=xlsx|pdf` для организатора этого события.

#### Scenario: Экспорт в Excel

- **WHEN** организатор запрашивает `format=xlsx`
- **THEN** ответ — файл `.xlsx` с колонками Фамилия, Имя, Отчество, Email, Телефон, Статус, Время чек-ина

#### Scenario: Экспорт в PDF

- **WHEN** организатор запрашивает `format=pdf`
- **THEN** ответ — файл `.pdf` с теми же колонками

#### Scenario: Неизвестный формат

- **WHEN** `format` не равен `xlsx` или `pdf`
- **THEN** ответ 400

### Requirement: Доступ только организатору

Система SHALL отклонять экспорт для пользователей, не являющихся организатором события.

#### Scenario: Чужое событие

- **WHEN** экспорт запрашивает другой организатор или участник
- **THEN** ответ 403

### Requirement: Состав данных

Система SHALL включать в экспорт только регистрации со статусами `registered` и `checked_in`; служебные поля и внутренние идентификаторы в файл не попадают.

#### Scenario: Отменённые регистрации

- **WHEN** у события есть отменённые регистрации
- **THEN** их нет в экспортированном файле
